Современное приложение для заметок с поддержкой текста и изображений. Разработано с использованием лучших практик Android-разработки: Jetpack Compose, Clean Architecture и современных библиотек.

✨ Возможности
📝 Создание и редактирование заметок с текстом и изображениями

🖼 Эффективная работа с изображениями через Coil

💾 Локальное хранение данных с Room Database

🎨 Адаптивный дизайн с поддержкой темной и светлой темы

🔄 Clean Architecture для масштабируемости и тестируемости

🛡 Безопасное управление файлами изображений

🛠 Технологический стек
Архитектура
Clean Architecture + MVVM - разделение на data, domain, presentation слои

Jetpack Compose - современный декларативный UI

Material Design 3 - система дизайна

Data Layer
Room Database - локальное хранение данных

Repository Pattern - абстракция доступа к данным

Kotlin Coroutines - асинхронные операции

Работа с изображениями
Coil - эффективная загрузка и кэширование изображений

Внутреннее хранилище - изоляция пользовательских данных

Инфраструктура
Hilt/Dagger - внедрение зависимостей

Navigation Component - навигация между экранами
